# プライバシーポリシー

_最終更新: 2026-07-24_

Menreiki は個人データを一切、収集・保存・送信しません。

- **テレメトリ・分析・クラッシュレポートはありません。** アプリケーション
  自身がネットワーク接続を行うことはありません。
- **すべての処理はローカルで完結します。** 文書の解析・OCR・変換・監査は
  すべてあなたのPC上で実行されます。文書とその派生物（ページ画像・OCR
  テキスト・レビューの判断）は、あなたの管理下にあるデバイス上の
  プロジェクトフォルダから出ません。
- **任意のローカルAI補助**は、あなた自身が設定した `localhost` 上の
  OpenAI互換エンドポイントにのみ接続します。localhost 以外への接続は
  構造的に拒否されます。この機能を通じて文書内容が外部へ出ることは
  ありません。
- **アカウントはありません。** サインイン不要で、サーバー側も存在
  しません。

以上は配布経路（GitHub Releases・winget・Microsoft Store）を問わず
同一です。

本ポリシーの変更は
[リポジトリ履歴](https://github.com/ShortArrow/Menreiki/commits/main/docs/PRIVACY.jp.md)
で確認できます。お問い合わせ:
[GitHub Issues](https://github.com/ShortArrow/Menreiki/issues)。
