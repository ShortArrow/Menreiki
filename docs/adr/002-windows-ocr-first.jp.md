# ADR-002: OCRの第一実装はWindows OCRとし、言語は明示指定する

- ステータス: 承認済み
- 日付: 2026-07-17

## 文脈

MVPはWindows優先（PRD §19.1）で、日本語・英語混在文書のOCR（§12.1）が
必要。候補はWindows OCR（OS内蔵）、Tesseract、ONNXローカルモデル。
OCRエンジンは交換可能にする要件がある（§19.6）。

## 決定

- OCRは `menreiki-ocr` のポート（trait）として定義し、第一実装は
  Windows OCR（Windows.Media.Ocr）とする。日本語精度が高く、モデル
  配布不要で完全オフライン
- 言語は既定で `ja` を明示指定する。ユーザープロファイルの言語順に
  任せると英語環境でen-USエンジンが選ばれ、日本語文書の認識が全滅する
  事故を実測したため
- Windows OCRの入力上限（MaxImageDimension）を超えるページは縮小して
  認識し、座標を原寸へ逆スケールして返す

## 帰結

- Linux/macOS対応時はTesseract等の別アダプター追加が必要（ポートは
  既にその形になっている）
- Windows OCRは日本語行を1文字ずつの単語として返すため、行テキストは
  エンジン任せにせず単語ボックスの幾何情報から合成する（ADR-004の
  頑健マッチングの前提）
