# ADR-003: 出力PDFは変換済みページ画像のみから自前構築する

- ステータス: 承認済み
- 日付: 2026-07-17

## 文脈

黒塗りツールの典型的な事故は「見た目は消えているが内部データに元の
テキスト・画像が残る」こと（PRD §2, §26.4）。既存PDFの部分編集や、
高機能なPDF生成ライブラリの利用は、元文書の構造が出力へ漏れる経路を
残す。

## 決定

- 出力PDFは、変換済みページ画像（ピクセル）だけを入力とする自前の
  最小PDFライター（menreiki-render）で新規構築する。DeviceRGBの画像
  XObject + FlateDecodeのみを使う
- 元PDFのオブジェクト（テキストレイヤー・注釈・添付・メタデータ・
  スクリプト・非表示レイヤー）は参照すらしないため、混入が構造的に
  不可能
- Markdown出力も同じ原則に従い、変換済みページ画像の再OCR結果のみから
  生成する（元のOCRテキストの流用は、マスク領域下の文字列が漏れるため
  行わない）

## 帰結

- 出力PDFは検索不能な画像PDFになる。検索可能PDFが必要になった場合は、
  置換後の再OCR結果から新しいテキストレイヤーを構築する（PRD §14.3の
  方針どおり、元テキストの再利用はしない）
- 生成PDFの正しさはpdfiumで再レンダリングして画素比較するラウンド
  トリップテストで担保する
