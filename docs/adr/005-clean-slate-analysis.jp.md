# ADR-005: 解析はクリーンスレート実行を既定とし、再開・ステージ実行を明示操作にする

- ステータス: 承認済み
- 日付: 2026-07-18

## 文脈

解析は冪等ではない（OCRエンジン・モデル・DPIの変更で結果が変わる）。
クラッシュや旧設定の部分結果が新しい結果と混ざると、「今見ている
findingsがどの設定の産物か」が分からなくなり、再現性（PRD §19.4）と
監査の信頼が壊れる。一方で100ページ級の文書では途中再開の価値も高い
（§19.3）。

## 決定

- 通常の解析・再解析は、解析派生物（ページ画像・OCR・findings・
  renders・output・audit・編集計画）を全消去してから実行する
  （menreiki-projectの `clear_analysis`）。原本・判断・辞書・Entityは
  ユーザーの作業成果であり消去対象外
- 再開（既存ページのスキップ）とステージ実行（画像化のみ・OCRのみ・
  検出のみ)は、ユーザーが明示的に選んだ場合のみ行う
- ページ処理は1ページ完了ごとにファイルへ書き、進捗コールバックの
  戻り値でページ境界キャンセルを受け付ける

## 帰結

- 「古い結果が現在の結果に見える」事故が構造的に起きない
- ステージ実行を選んだ場合の整合性（例: 画像化のみ後のOCRの鮮度）は
  ユーザー責任となる。これはモデル差し替え検証などの意図的な使い方の
  ためのエスケープハッチである
