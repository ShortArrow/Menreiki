# ADR-006: ローカルLLM統合はOpenAI互換ローカルAPIへの薄いクライアントで行う

- ステータス: 承認済み
- 日付: 2026-07-17

## 文脈

Phase 2でローカルLLM/VLMによる文脈依存検出・仮称提案・図表内候補検出
（PRD §12.6）を予定している。統合手段としてRust製エージェント
フレームワーク（zavora-ai/adk-rust: Apache-2.0、39クレート、クラウド
プロバイダ中心のネイティブ対応）を検討した。

## 決定

- `menreiki-inference` はOpenAI互換ローカルAPIへの薄い自前HTTP
  クライアントとして実装する。接続先はlocalhostに限定し、原文の外部
  送信（PRD §18.3）を構成レベルで防ぐ
- llama.cpp server / Ollama / LM Studio / mistral.rs はいずれも
  OpenAI互換エンドポイントを提供するため、この1実装でモデル非依存
  （§20.7）を満たす。VLMの画像入力も同API形式で通る
- adk-rustは現段階では採用しない。必要なのは「画像+プロンプト→JSON」の
  1往復推論であり、エージェントループ・RAG・セッション管理を含む
  39クレートの追加はSBOM・監査コスト（§18.6）に反する。クラウドへ
  容易に接続できるSDKを機密文書処理のコアに入れることはローカル
  ファースト保証を弱める

## 帰結

- Phase 2で自動Entity統合のようなエージェント的多段ワークフローが
  必要になった場合、オーケストレーション層としてadk-rustを再評価する
