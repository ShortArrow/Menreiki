# ADR-007: MIT OR Apache-2.0のデュアルライセンスで公開する

- ステータス: 承認済み
- 日付: 2026-07-18

## 文脈

PRD（§28）はOSS公開を方針として掲げるが、ライセンスの種類は未指定
だった。コアはRustで、エコシステムの大半のクレートはMIT/Apache-2.0の
デュアルライセンスを採る。

## 決定

MIT License と Apache License 2.0 の選択式デュアルライセンスとする。

- Rustエコシステムの慣例に一致し、依存関係・被依存の両方向で摩擦がない
- Apache-2.0の特許条項と、MITの単純さの両方を利用者が選べる
- 全クレートは `workspace.package` の license を継承し、意図的な貢献は
  同条件で受け入れる

## 帰結

- 同梱するサードパーティ（PDFium等）の帰属表示は
  THIRD-PARTY-NOTICES.md に集約して配布物へ含める
