# ADR-008: プロジェクトはフォルダ形式とし、project.mnrkを開く入口にする

- ステータス: 承認済み
- 日付: 2026-07-19

## 文脈

「フォルダを開く」操作は一般ユーザーに馴染みが薄い。代替として
xlsx型のzip単一ファイルと、slnx型の外部プロジェクトファイルを検討した。

- zipコンテナ: 100ページ×300dpiでページ画像だけで数百MBになり、
  自動保存のたびにアーカイブ全体を書き直すことになる。書き込み中の
  クラッシュでアーカイブごと壊れ、1ページ完了ごとの逐次書き込みに
  依存するキャンセル・再開の安全性が失われる。ビューアが直接読めない
  ため機密ページを一時領域へ展開する必要が生じ、PRD §18.5と衝突する
- 外部プロジェクトファイル（データフォルダと別の場所に置く形）:
  ファイルだけ移動されて対応が壊れる事故が定番

## 決定

- プロジェクトのデータは従来どおりプレーンなフォルダとする
- マニフェストをフォルダ内の `project.mnrk`（内容はJSON）とし、これを
  「開く」対象・ダブルクリック対象にする。フォルダ内にあるため
  ファイルとデータが分離しない
- 開く操作はフォルダでも `.mnrk` ファイルでも受け付け、共通の解決
  関数で正規化する。旧 `project.json` は読み込み互換を維持する
- 持ち運び用途には、将来「zipへの明示的なパック/アンパック（交換用
  エクスポート）」を追加する。作業状態のフォーマットにはしない

## 帰結

- インストーラーとアプリ内登録（ADR-009）で `.mnrk` の拡張子関連付けが
  でき、一般ユーザーはファイルのダブルクリックで開ける
- 逐次書き込み・クラッシュ安全・一時展開なしの性質は維持される
