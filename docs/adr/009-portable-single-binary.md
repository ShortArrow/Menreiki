# ADR-009: ポータブル単一バイナリを主配布形態とし、pdfiumを埋め込む

- ステータス: 承認済み
- 日付: 2026-07-19

## 文脈

インストーラーより単一バイナリ配布が好まれる。障害は実行時に必要な
pdfium.dll（プリビルトの動的ライブラリで、供給元は静的リンク用の
成果物を配布していない）だけだった。ライセンスを確認した結果、
PDFiumはBSD-3-Clause / Apache-2.0のデュアルライセンスで、バイナリへの
同梱・再配布は帰属表示を条件に許可されている。

## 決定

- デスクトップ・CLIの両実行ファイルにpdfium.dllをコンパイル時に埋め込む
- ライブラリの解決順: `MENREIKI_PDFIUM_PATH` → 実行ファイルと同じ
  ディレクトリ → 作業ディレクトリ祖先の `vendor/pdfium`（開発配置）→
  埋め込みコピーを `%LOCALAPPDATA%\Menreiki\pdfium\<内容ハッシュ>\` へ
  展開。内容ハッシュ付きパスにより更新時の衝突と再展開を避ける
- 帰属表示は THIRD-PARTY-NOTICES.md として配布物へ含める
- `.mnrk` 関連付けは、インストーラー利用時はNSISが、ポータブル利用時は
  アプリ内のHKCU登録（管理者権限不要）が行う
- NSISインストーラーも同一ビルドから併存させる（標準的な
  インストール/アンインストールUXを求める利用者向け）

## 帰結

- 配布は「exeを1個渡すだけ」になる（デスクトップ約27MB、CLI約19MB）
- WebView2が前提となるが、対象環境のWindows 11には標準搭載されている
- ビルドには `vendor/pdfium/pdfium.dll`（scripts/fetch-pdfium.ps1で取得）
  が必要になる
