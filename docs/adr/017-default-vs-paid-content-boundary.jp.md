# ADR-017: デフォルト検出と有償コンテンツの境界を定める

- ステータス: 承認済み
- 日付: 2026-07-27

## 文脈

検出パック（ADR-016）は将来の収益化（オープンコア）の候補単位である。
「何を本体に同梱し、何を有償パックとして売ってよいか」の基準が無いと、
判断が場当たりになり、最悪の場合「基本的な安全を金で売る」構図に
踏み込んで、本製品の信頼（QUALITY.jp.md の約束）を毀損する。

## 決定

有償コンテンツにしてよいのは、次の**3テスト全てにYES**のものだけとする。
1つでもNOなら本体デフォルト（無料）に置く。

1. **安全底線テスト** — それが無くても、一般的な日本のビジネス文書の
   匿名化が危険にならないか？（危険になるなら無料）
2. **垂直性テスト** — 特定の業種・用途でのみ価値を持つか？
   （汎用なら無料）
3. **キュレーション価値テスト** — 中身は公知の形式仕様の転記ではなく、
   収集・検証・継続保守という労力の結晶か？（公知形式の転記なら無料）

補助原則:

- **検出エンジンの機能は、すべて・恒久的に無料。** 有償化してよいのは
  データ（検出内容）だけであり、機能（行結合・VLM連携・監査・出力等）を
  ゲートしない。この項の変更は本ADRの棄却を意味する。
- **迷ったら無料側に倒す。** 信頼が事業資産であり、取り分の最大化より
  底線の明確さを優先する。
- 有償パックが無くても、監査（audit）が通常文書で成立すること。

## 帰結

- 無料バックログ: マイナンバー（チェックディジット検証付き）・法人番号・
  クレジットカード番号（Luhn）・運転免許証番号など、**法令・公的規格で
  形式が公知の個人識別情報**は本体検出器に追加していく（テストA/Cで
  自動的に無料側）。
- 有償候補: 業種特化パック（製造業の図面表題欄・型番体系群、医療、
  建設、金融、法務契約）、継続更新される専門語彙・パターン集、
  組織専用パックの受託作成（サービス）。
- 配布パックの実在名の扱いを精緻化する: **実在の個人名は配布物に
  含めない**（プライバシー）。**公知の法人名・公的機関名のリスト**
  （企業名鑑・病院名簿等）は公開情報であり、有償パックの正当な
  コンテンツになり得る。DETECTOR-PACKS.jp.md に反映する。
