# テスト文書（Typst ソース）

`scripts/make-test-documents.ps1` がここの各 `.typ` を `test-documents/<名前>.pdf`
へコンパイルします。実在の会社・人物・製品は使わないこと（すべて架空名）。

| ファイル | ユースケース | 主な検証ポイント |
|---|---|---|
| `dummy-spec.typ` | 一般的な技術報告書（E2Eの標準フィクスチャ） | 組織/人物/連絡先/識別子の検出、ヘッダー・フッター、検索→置換→出力→監査の全工程 |
| `letter-spaced-title.typ` | 図面表題欄の字間スペース社名 | 1文字断片の行内再結合、footer ではなく organization として検出 |
| `rotated-landscape.typ` | 横向きページ＋90度回転ラベル | 横向きでの矩形座標、縦1文字列の前後読みでの社名再構成 |
| `block-diagram.typ` | 機能ブロック図 | 「受信部/生成回路」誤検出の無視運用、矢印に沿う細長い誤矩形の抑止、凡例の扱い |
| `wiring-table.typ` | 罫線表（MAIN+28 の縦列） | 「+28」格子から電話番号を捏造しない、隣接セルを1語に結合しない |
| `contract-aliases.typ` | 契約書の別名定義 | 「○○」と称する 構文の固有名詞検出、カタカナ法人接尾辞、略称のEntity統合 |

新しい不具合を修正したら、可能な限り対応する `.typ` を追加・更新して
実文書に近い形で再現できるようにしてください。
